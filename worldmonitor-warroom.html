2 Turn on the trader layers

Open LAYERS (bottom-left of the map) and enable the ones that move markets:

🎯Intel hotspots + conflict zones — where risk premium is being priced right now.
🚢Undersea cables, pipelines & chokepoints — Hormuz, Suez, Malacca: when these light up, oil and shipping move.
🛢Storage facilities + fuel shortages — the physical-economy tell behind energy prices.
☢️Nuclear sites + military bases — the escalation map headline-writers react to hours later.

3 Read it like a trader

The workflow from the post — four data layers, one screen:

FEEDS → live wires from 500+ outlets land in the intel feed.
MAP → each story is pinned where it's happening; clusters = something's building.
NEWS → world + US streams give you the mainstream read.
BRIEF → the AI-synthesized situational summary ties it to what's moving on the tape.

Check the Infrastructure Cascade and Force Posture panels before big macro sessions — flight clusters and cascade links often front-run headlines.

5 Self-host from GitHub

It's fully open-source (AGPL). Four commands, runs with zero environment variables:

git clone https://github.com/koala73/worldmonitor.git cd worldmonitor npm install npm run dev

Open localhost:3000. For the finance lens: npm run dev:finance.

→ github.com/koala73/worldmonitor — star it to say thanks. Self-hosting guide: docs.

6 No API keys — even the AI is optional-local

The dashboard needs no keys. If you want the AI briefs generated on your own machine, point it at Ollama — everything stays local. Groq / OpenRouter work too if you prefer hosted models.

! Good to know

It's context, not signals. The war-room tells you why the tape is moving — it doesn't tell you what to buy. Treat every alert as a research prompt, not a trade.

Sources vary in reliability. Feeds are labeled (reviewed / unreviewed) — check the tag before acting on a headline.

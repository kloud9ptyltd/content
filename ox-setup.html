Set it up in 3 minutes

No install. Works on your phone or laptop. You only need a free account.
  1. Go to openrouter.ai and create a free account. This is the "app store" where the mystery model lives alongside hundreds of others.
  2. Create a free API key (Keys → Create Key). Copy it. Never share it — it's like a password.
  3. Pick a free model. Open the model list and filter by "Free" — the stealth/mystery model sits at the top by usage. Select it and start chatting, or drop it into any script.
# Talk to it from anywhere (swap in YOUR key + the current free model id):
curl https://openrouter.ai/api/v1/chat/completions \
  -H "Authorization: Bearer YOUR_OPENROUTER_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"<the-free-model-id>","messages":[{"role":"user","content":"Explain a covered call like I am 15, with a dollar example."}]}'

The Two-Twist Story

7 of 8 lost money. All 8 beat the market.

The only "winner," SuperTrend, made +1.41% in fourteen months — a savings account beat it. And yet every single one of these eight scripts beat buy-and-hold (−20.2%). In a falling market, even bad long-only timing beats full exposure. The indicators' real, mostly accidental value was keeping you out.

The Repaint Exposé

Same envelope. Same rules. One time machine.

Nadaraya-Watson Envelope

Identical indicator, identical entry/exit rules, identical window (2025-07-17 → 2026-08-22, market −35.6%). The only difference: which window of candles the indicator is allowed to look at.

Tested honestly (causal)
−5.62%
  • win rate 55.6% · PF 0.62 · MaxDD 7.30%
  • the indicator only ever sees the past
As it draws on your chart (repaints)
+35.30%
  • win rate 91.7% · PF 31.59 · MaxDD 0.51%
  • uses the centered, future-using window the indicator actually paints

The version drawn on your live chart quietly recalculates the past using candles that haven't happened yet when you'd need to act on them. That's why it looks perfect — the perfect indicator, powered by a time machine.

The lookahead-by-design code that produces the +35.30% number is deliberately not distributed here. Anyone who ran it would see a 91.7%-win-rate "system" and think they'd found the holy grail. They'd have found a clock, not an edge.
The Verdict

Across all 13 tested, only two scripts made money.

SuperTrend +1.41% and Chandelier Exit +2.08% — the only two profitable scripts across everything on this bench. Both are pure ATR trailing stops. No oscillator survived. No machine learning survived. No community legend survived, except the one built from the same primitive.

Run It Yourself

Seven Pine v5 strategies, paste-ready.

Chart: BTCUSDT.P (Binance), 1h — to mirror this bench. For the Golden Cross, flip the chart to 1D or 1W. Paste ONE strategy at a time into the Pine Editor; each block is standalone.

1 · RSI 30/70 (the meme baseline)
−9.29% on this bench
//@version=5
strategy("C9 Bench: RSI 30/70", overlay=false, initial_capital=10000, default_qty_type=strategy.percent_of_equity, default_qty_value=100, commission_type=strategy.commission.percent, commission_value=0.05)
r = ta.rsi(close, 14)
if ta.crossover(r, 30)
    strategy.entry("L", strategy.long)
if r > 70
    strategy.close("L")
plot(r)
hline(30), hline(70)

atr = 3.0 * ta.atr(22)
longStopBase = ta.highest(close, 22) - atr
shortStopBase = ta.lowest(close, 22) + atr
var float ls = na
var float ss = na
ls := close[1] > nz(ls[1], longStopBase) ? math.max(longStopBase, nz(ls[1], longStopBase)) : longStopBase
ss := close[1] < nz(ss[1], shortStopBase) ? math.min(shortStopBase, nz(ss[1], shortStopBase)) : shortStopBase
var int dir2 = 1
dir2 := dir2 == 1 ? (close < ls ? -1 : 1) : (close > ss ? 1 : -1)
if ta.change(dir2) > 0
    strategy.entry("L", strategy.long)
if ta.change(dir2) < 0
    strategy.close("L")

Honesty Rails

What this bench is — and what it isn't.

Read this before you trade any of it
  • This is crypto perps, 1h candles, one 14-month window that happened to be a down market (−20.2%). A different window, timeframe, or market gives different numbers.
  • Say "on this test" — not "these never work."
  • Every strategy above is long-only, canonical default settings, signal exits only — no stop-loss, no tuning, no shorting. Any of those would change the results.
  • This is the same bench and the same fee model that has already killed 180+ of our own AI-built strategies. It isn't rigged against TradingView's indicators — it's just consistent.

The idea · how it holds together

Four rules make it a desk.

1
Claude writes the desk

The whole thing is built and driven with Claude Code. You describe an agent in plain English; it writes the service. That's what turns "an AI that talks" into a team that does the work.

Highly recommended

Run it on Claude's Fable 5 model. An orchestrator that routes one spoken command to the right specialists — and knows when to stop and let the risk officer say no — lives or dies on reasoning quality. Fable 5 is the difference between a real desk and nine chatbots talking over each other. Why Fable 5 for finance →

2
One master, many specialists

Each agent is its own independent service with a single job and a clean way to talk to the others. The master is the only one that talks to you — it delegates down and synthesizes up. Adding a tenth agent later doesn't touch the other nine.

3
The charts are part of the desk

The technician doesn't describe the chart — it drives it. Claude connects to TradingView through an open-source MCP server, so "pull up Nvidia and mark the levels" is a command, not a request. This is the part that makes people rewind the video.

4
The one rule that makes it safe

Money moves through exactly one gated path: a proposal only becomes a trade after Sentinel stamps it. Analysis can't execute; execution can't self-authorize. The risk officer is built into the architecture — not bolted on.

⚠️ What it is — and isn't: this is a research and awareness co-pilot with a built-in risk officer, not a money printer. It surfaces structure and context; it does not tell you what will happen next. Educational, grounded, and not financial advice — always do your own research.

Build it yourself · the weekend path

Every piece is free.

The stack that looks like Iron Man's lab is, piece by piece, free software you can install tonight. Here's the honest shopping list:

1
The shell

Ask Claude Code for an Electron app (a desktop web page, basically): a dark HUD, nine agent seats, one glowing orb. Claude writes all of it — the visual taste is the only part you supply.

2
The voices — $0

Local TTS gives every agent a distinct voice for free: Voicebox running the open-source Kokoro engine — dozens of voices, ~2 seconds a clip, entirely on your machine. (ElevenLabs is the paid upgrade if you want Hollywood polish — you don't need it to start.)

3
The ears — $0

Voice in is whisper.cpp — OpenAI's speech recognition running locally. Your app hears you finish a sentence and acts. No cloud, no per-minute fees.

4
Live market data — $0

A free Finnhub key covers quotes, movers and news; yfinance covers history. Every number the desk speaks should come from a real feed — a desk that invents prices is a toy.

5
The chart takeover — $0

Connect Claude to TradingView with the open-source MCP server so the desk can flip symbols and draw on your real charts. I wrote the full setup guide: Claude Code × TradingView Desktop →

6
The starter prompt

Open Claude Code in an empty folder and start with this — then iterate one agent at a time:

Build me an Electron app called "my trading desk": - a dark cinematic HUD with 9 agent seats arranged around a glowing central orb - each agent has a name, a role (macro / smart-money / recon / analyst / technician / quant / risk / execution / journal) and its own TTS voice - a master agent that takes my typed or spoken command, decides which specialist should answer, and speaks the reply out loud - live quotes from the Finnhub API (I'll paste my free key) - one hard rule: any "trade" action must be approved by the risk agent first Start with the HUD and two agents; we'll add the rest one by one.
Straight talk

F.R.I.D.A.Y. is not a download. There's no installer, no repo to clone — I custom-built it for Cloud9, and the nine agents run on my own tools, skills, orchestration and backend wiring that won't copy-paste into your setup. What this page gives you is the high-level design: the architecture, the rules, and the free building blocks — so you can build your version, shaped to what you actually need (three agents might be plenty).

The building blocks I genuinely use, to get you started: MediaPipe (Google's hand tracking, runs in the browser) · Electron (the desktop shell) · whisper.cpp (local speech-to-text) · Kokoro (free local TTS voices; ElevenLabs if you want the paid polish) · Finnhub + yfinance (live + historical market data) · and the TradingView MCP setup for the chart control.

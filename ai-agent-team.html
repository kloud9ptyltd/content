Step 1

The brain: free AI models

Every agent gets a free model. Most come from OpenRouter (openrouter.ai): one API key, dozens of models whose ids end in :free. The desk's "thinkers" (the chief, the leads, bull and bear) try Google Gemini's and Groq's free tiers first.

One key, many labs

Assign each agent a model from a different lab, so the desk isn't relying on a single provider. Ours: NVIDIA Nemotron, Qwen, InclusionAI Ling (finance-tuned), Poolside Laguna, Liquid LFM, Nex — models from different AI labs.

A weak or busy model in a synthesis seat sinks the whole brief, so the chief, the leads and the bull/bear analysts try Gemini 2.5 Flash (Google AI Studio free tier) and Qwen on Groq (free tier) first, and fall back to OpenRouter's free models when those run out of quota.

NVIDIA Nemotron Qwen InclusionAI Ling Poolside Laguna Liquid LFM Nex Google Gemini Groq

Honest limits: free models are often busy, so every agent gets 2 backup models. They're also rate-limited — at the time of writing, roughly 50 requests/day on a brand-new account, far more once you've added credits; check OpenRouter's current docs. The list of free models changes often.

The golden rule

Never let the AI do the maths. Python pulls the data (price, news, SEC filings, insider trades) and calculates every number. The AI only writes sentences about numbers it's handed, and a checker flags any number it didn't get from the data.

Step 2

The characters: ChatGPT image generation

How the mascots were made, start to finish.

  1. Design the 6 leads together. Sketch all 6 lead characters (chief + 5 desk leads) on one board, so their species, proportions and material language agree with each other.
  2. Generate each alone. Pull each lead out on its own, on a genuinely transparent background.
  3. Give it a resting pose. Same character, eyes closed, a quiet second pose for when it's on standby.
  4. Specialists as junior siblings. Each specialist reuses its lead's body, colour and material, but rounder and cuter, with its own small prop so it still reads as its own character.

Tip: do a whole department in one chat, attaching the lead's ready image as reference each time, so the style stays consistent.

Step 3

The harness: how the agents work together

Two layers: a fixed Python pipeline as the spine, and Hermes Agent, an open-source agent harness, for the jobs that need a real agent.

Layer 1: the pipeline (the spine)

A plain Python script runs the same steps in the same order every time. That keeps it cheap and predictable, and every number can be checked. For a ticker, the script:

  1. Fetches the data. At the same time, the web scout searches the web through Hermes.
  2. Runs the specialists in parallel.
  3. The Chief reads their headlines and writes a plan, again through Hermes (see below).
  4. Each lead reads its specialists' reports, answers the Chief's question and writes a desk pack.
  5. The bull and bear analysts argue from all the packs, and the review lead weighs the two cases.
  6. The Chief writes the final brief, including what changed since the last one.

Layer 2: Hermes Agent (live now)

Hermes Agent is Nous Research's open-source agent harness: you give a model tools and a goal, and it decides what to do. On the desk it does three jobs:

  1. The web scout. The Research Analyst uses Hermes's web search to find the last 7 days of coverage for the ticker, with at most 3 searches. Python then keeps only links that really appeared in the search results, so an invented link is dropped automatically.
  2. The Chief's plan. Before the leads start, Hermes reads every specialist's headline and gives each desk lead one question to answer. You'll see it in the desk chat as "Chief's plan".
  3. Memory. The Chief is shown its last brief for the same ticker: what it said to watch, and how far the price has moved since then. Python works out that move; the AI doesn't. The brief gets a "Since last brief" line.

The safety net: Hermes is optional. If it's missing, busy or fails, the run carries on as the plain pipeline and notes the gap. The Hermes profile has only the web search tool switched on (no terminal, no files), and it gets only the one API key it needs, not your other secrets.

Every message is logged

Every message is saved to a small SQLite database: who wrote it, to whom, which model, how long it took, its sources and a receipt id. Hermes's searches are logged too ("Searched the web: …"). That log is what the web page replays, and it's why you can watch the agents "talk".

The web page

One HTML file that reads that log: a Team view, an Agent view, a Desk chat, plus an "Ask" box where visitors question an agent. The Ask box answers only from that run's notes and never calls Hermes, so a visitor can't make the agents browse. It's rate-limited and never gives advice. The page also has a US Market mode: a market-wide brief (index moves, sector rotation, the week's earnings) that runs each morning before the NVDA brief.

Add Hermes to your own desk

  1. Install Hermes Agent from its GitHub repo and point it at your OpenRouter key (or Gemini or Groq).
  2. Make a separate profile just for the desk, and switch on only the web toolset. Ours uses DuckDuckGo search, which is free and needs no key.
  3. Call it from Python as a one-shot command and read its JSON event stream:
    hermes -p desk chat -Q --oneshot --format stream-json -m <model> --max-turns 8 --query-file prompt.txt
  4. Check its work in Python: parse the final answer as JSON (don't trust the exit code), keep only URLs that show up in its own search results, and try the next model if it's rate-limited.

Step 4

Hosting, free

It runs on an Oracle Cloud "Always Free" ARM server (currently 2 CPU / 12 GB RAM; free-tier capacity depends on region and availability, and Oracle has changed the allowance before). A free Cloudflare Tunnel puts it online without opening any ports. A daily timer runs the team each morning after the US close: the US Market brief first, then NVDA. Hermes Agent runs on the same box.

Step 5

Get the brief delivered

Don't go to the page; have the Chief's brief come to you each morning.

Discord (easiest, free)

  1. Make a channel for it, e.g. #desk-brief.
  2. Create a webhook: Server Settings → Integrations → Webhooks → New Webhook. Pick the channel, give it a name and an avatar (your Chief mascot works well).
  3. Copy the webhook URL and store it as a secret (an environment variable), never in your code. Anyone with that URL can post to your channel.
  4. After each run, POST the brief to that URL as JSON: the headline as the title, the summary, key facts, the bull and bear cases. Turn mentions off so it can never ping @everyone.

Discord's guide: Intro to Webhooks.

Telegram (free, pings your phone)

Message @BotFather on Telegram, send /newbot and keep the token it gives you (as a secret). Send your new bot a message, then your script can post the brief to that chat with the Bot API's sendMessage. Telegram's guide: From BotFather to "Hello World".

WhatsApp

It can also be done through the WhatsApp Business Platform, but it needs a verified business account, approved message templates and per-message fees, so Discord or Telegram is the easier free route.

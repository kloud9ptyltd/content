What it actually is

Your terminal agents, given desks.

The engine is Munder Difflin — an open-source multi-agent harness (MIT, by Chaitanya Giri). It wraps the coding CLI you already run — Claude Code, Codex, Gemini CLI, Grok, Copilot, Cursor and more — into a team: each agent gets a seat, a terminal, a memory, and a manager. The manager is Michael, a clone of you that routes work, checks in on agents, and keeps the office moving on your hourly limits while you sleep. I tuned my copy into the Cloud9 Trading Desk — renamed the cast, added the ticker and market signage, pointed the agents at finance work.

Install & run · the actual steps

Your own office, in ten minutes.

1
Check the prerequisites

Node.js 18+ and npm, plus a C/C++ toolchain for the terminal engine. On a Mac that's one line:

xcode-select --install

Works on macOS, Windows and Linux.

2
Have at least one agent CLI installed

Any one of the 12+ supported CLIs on your PATH is enough — Claude Code (claude) is the default; Codex, Gemini CLI, Grok, Qwen, OpenCode, Copilot and Cursor all work. Missing CLIs mostly self-heal — the harness runs the installer in the terminal for you. Your existing subscription is the fuel; no extra API bill required (your own keys and local models via Ollama/LM Studio are optional).

3
Clone, install, run
# three commands, that's the whole install git clone https://github.com/chaitanyagiri/munder-difflin.git cd munder-difflin npm install # rebuilds the terminal engine for Electron npm run dev # the office opens
4
Walk the floor

First launch runs an onboarding wizard, then you land on the floor. Hit Add agent to spawn your first session — your clone seats itself in Michael's office automatically and starts coordinating. Set triggers (time-of-day, weekday-aware) so the office works on a schedule, and give agents goals in plain English.

5
Make it yours

The cast, roles, and goals are all config. I turned mine into a trading floor — yours can be a coding team, a research desk, a content studio. Rename the agents, change the signage, point them at your work.

Straight talk

Credit where it's due: the harness is open-source work by Chaitanya Giri (MIT). My trading floor is a reskin and configuration on top — you bring your own AI CLI and accounts. And the desk is a demo/creative setup, not a live trading system: agents run paper-only behind Sentinel's gate.

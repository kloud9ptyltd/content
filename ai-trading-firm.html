Your own AI trading firm

TradingAgents is a free, open-source framework that turns AI models into a research desk: four analysts, a bull and a bear who argue, a trader, a risk team and a portfolio manager who makes the call. Below is the exact setup, what a run costs, which model to put in the chair, and every NVDA call we have run through it, marked to market.

01 · Build it

The exact setup

Python 3.12+ and about five minutes. Verified on TradingAgents v0.3.1.

  1. 1

    Clone and install

    The repo is TauricResearch/TradingAgents on GitHub.

    git clone https://github.com/TauricResearch/TradingAgents.git
cd TradingAgents
python3 -m venv .venv && .venv/bin/pip install .
  2. 2

    One key runs every brain

    One OpenRouter key reaches every model, including the cheap DeepSeek ones that make a run cost cents. Create a .env in the repo folder:

    OPENROUTER_API_KEY=sk-or-v1-your-key
TRADINGAGENTS_LLM_PROVIDER=openrouter
TRADINGAGENTS_DEEP_THINK_LLM=deepseek/deepseek-chat
TRADINGAGENTS_QUICK_THINK_LLM=deepseek/deepseek-chat
TRADINGAGENTS_MAX_DEBATE_ROUNDS=2
TRADINGAGENTS_MAX_RISK_ROUNDS=2

    Have Claude API credit instead? Use your Anthropic key directly. This is the setup behind our November run (Opus as the manager, Haiku for everyone else):

    ANTHROPIC_API_KEY=your-key
TRADINGAGENTS_LLM_PROVIDER=anthropic
TRADINGAGENTS_DEEP_THINK_LLM=claude-opus-5-5
TRADINGAGENTS_QUICK_THINK_LLM=claude-haiku-5-5
TRADINGAGENTS_MAX_DEBATE_ROUNDS=3

    Important for Claude 5.5 models: read the blank-bear fix below first, or the bear agent can go silent.

  3. 3

    Free macro data (optional)

    Stock data comes from yfinance with no key. Add a free FRED key (fred.stlouisfed.org) to the .env as FRED_API_KEY=... and the news analyst gets real Federal Reserve data: rates, inflation, jobs.

  4. 4

    Run the firm

    Launch from the repo folder (that is where the .env is found), pick a ticker and a date, and watch each desk light up in the terminal.

    .venv/bin/python -m cli.main
  5. 5

    Upgrade the brain when it matters

    Change one line to put a frontier model in the manager's chair. Same firm, sharper reasoning, higher price.

    TRADINGAGENTS_DEEP_THINK_LLM=openai/gpt-5.6-sol
  6. 6

    A real run, start to finish

    The CLI asks a few questions, then every desk runs live. Our August frontier run on NVDA, as of 2026-08-10:

04 · Which model

Swap the brain, flip the verdict

In August we held everything fixed (ticker, date, data, agents) and swapped only the model. The budget desk said Buy. The frontier desk said Underweight. Two runs on the same cheap model agreed with each other, so the flip is the model's personality, not random noise.

Fourteen weeks later NVDA is down 30%, so the expensive brain was right on direction. In November the Claude desk, with a working bear, also said Underweight. Our pick: a strong model in the two manager seats and a cheap, fast model for the team.

05 · Honest findings

What works, what fails

Works

The process is worth watching

Four analysts pull real data (fundamentals, technicals, headlines, sentiment), then a bull and a bear argue before a trader and a risk team weigh in. As a way to learn how a desk reasons, it is the best free tool in AI finance.

Fails · Claude 5.5 models

The blank bear

Claude 5.5 models think before they answer, and TradingAgents caps each answer at 4,096 tokens. In our first Opus run the bear spent the whole budget thinking and returned nothing in all three rounds, and the one-sided debate came back Overweight. With the cap raised, the same model said Underweight. Raise it in a short run script:

from tradingagents.graph.trading_graph import TradingAgentsGraph
from tradingagents.default_config import DEFAULT_CONFIG

orig = TradingAgentsGraph._get_provider_kwargs
TradingAgentsGraph._get_provider_kwargs = lambda self: {**orig(self), "max_tokens": 16000}

config = DEFAULT_CONFIG.copy()   # provider/models come from your .env
state, decision = TradingAgentsGraph(config=config).propagate("NVDA", "2026-11-17")
print(decision)

Then check that both bull_history and bear_history in the output have text before you trust a verdict.

Fails · budget models

A stop-loss at the current price

The budget desk put its stop at the price NVDA was trading at. The technical analyst had flagged that level as resistance and the cheap model recycled it without checking it against the price. A human risk manager catches that at a glance.

Fails · data

Reddit blocks the sentiment feed

The sentiment analyst reads Reddit's public RSS, which now returns HTTP 403 and 429 errors. The run still finishes on StockTwits and other sources, but for real Reddit data you need a proper scraper (for example an Apify Reddit actor).

Missing

No price target, by design

No agent does valuation math: no DCF, no comps, no earnings model. You get a desk-style decision (buy, hold or sell, plus sizing and risk) but never a 12-month target, whichever model you pay for.

THE HONEST LINE

A research tool in the shape of a firm: brilliant for learning how a desk reasons, dangerous if you trade its output raw. Its verdict can flip with the model you plug in. Treat every call as one intern's opinion, not an answer.

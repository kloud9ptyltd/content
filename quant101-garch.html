Quant 101 · Part 1:
GARCH

The Nobel-winning idea that forecasts how wild the market gets, not which way. Run it on any market in one command.

More free quant resources: start here →

01 · The code

Copy it. Run it.

Save this as garch_forecast.py. That is the whole thing.

garch_forecast.py · Python
# GARCH volatility forecast for any market. Quant 101, part 1 (cloud9markets.com)
# pip install yfinance arch      then: python garch_forecast.py QQQ
import sys, numpy as np, pandas as pd, yfinance as yf
from arch import arch_model

ticker = sys.argv[1] if len(sys.argv) > 1 else "QQQ"     # any Yahoo symbol: SPY, ^KS11, BTC-USD, NVDA
prices = yf.download(ticker, period="3y", auto_adjust=True, progress=False)["Close"].squeeze()
returns = 100 * np.log(prices).diff().dropna()          # daily % moves

fit = arch_model(returns, vol="GARCH", p=1, q=1).fit(disp="off")
w, a, b = fit.params["omega"], fit.params["alpha[1]"], fit.params["beta[1]"]
normal = np.sqrt(w / (1 - a - b))                         # long-run daily volatility
now = np.sqrt(fit.forecast(horizon=1).variance.iloc[-1, 0])
half_life = np.log(0.5) / np.log(a + b)                   # days for the extra risk to fade halfway
calm_date = pd.bdate_range(prices.index[-1], periods=int(round(half_life)) + 1)[-1]

print(f"{ticker}: last close {prices.index[-1]:%Y-%m-%d}, last move {returns.iloc[-1]:+.2f}%")
print(f"normal day: {normal:.2f}%   tomorrow's forecast: {now:.2f}%   ({now / normal:.1f}x normal)")
print(f"memory (alpha+beta) {a + b:.3f} -> half-life {half_life:.1f} trading days, about {calm_date:%b %d}")

04 · The three parts

Omega, alpha, beta.

  1. omega (ω) · the baseline

    The normal level that risk drifts back to.

  2. alpha (α) · today's shock

    Squared, so a 4% move counts 16 times more than a 1% move.

  3. beta (β) · memory

    Yesterday's volatility carrying into tomorrow.

  4. alpha + beta close to 1

    Long memory: shocks take a long time to fade.

σ²(t+1) = ω + α·ε²(t) + β·σ²(t)

06 · Before you use it

Read this before you use it.

  1. Size, not direction

    It forecasts the size of moves, not which way they go.

  2. "Predicts when it calms" is a model output

    It means the half-life estimate. It is not a promise.

  3. The data window matters

    A 10-year S&P fit gives a slower decay than a 3-year fit. Change period="3y" in the code and compare.

  4. The date ignores holidays

    The half-life date counts weekdays only.

  5. History

    ARCH by Robert Engle (1982, Nobel 2003). GARCH by Tim Bollerslev (1986).

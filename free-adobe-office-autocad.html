Adobe, Office & AutoCAD
rebuilt free, with AI

One developer used AI to rebuild 12 of the world's most expensive creative and office apps as free, open-source software, and added a way for AI agents to use every one of them.

By Cloud9 Research · checked 12 Oct 2026

Brandon Thomas, founder of ArtCraft (formerly CEO of Storyteller.ai), released the Craft App Suite: clean-room versions of Photoshop, Premiere Pro, Illustrator, Lightroom, After Effects, InDesign and Acrobat, plus Word, Excel, PowerPoint, AutoCAD and Pro Tools. They're written in Rust, licensed MIT/Apache, and run on Mac, Windows, Linux and in the browser. Press reports say they were built with Anthropic's Claude Opus 5.5. Adobe alone is a ~$94B company.

What "clean room" means

New code, not copied code

Nobody looked at Adobe's or Microsoft's source code. The apps were rebuilt from public file-format specs (like the open .xlsx and PDF standards) and from watching how the originals behave. Then AI wrote the new code. That's the long-standing legal technique for building compatible software without copying it.

Honest note: clean-room makes a "you copied our code" claim very hard, but it isn't a force field. Trademarks, patents and look-alike designs are separate questions. That's for lawyers, not a reason to avoid the apps.

Setup · 2 minutes

Install all 12 with one app

The official ArtCraft Launcher lists every app, downloads the right build for your computer, checks its SHA-256 checksum, and keeps everything updated.

  1. Download the Launcher for your system from github.com/storytold/craft-launcher/releases/latest. On a Mac, pick the file ending macos-universal.dmg; on Windows, the .msi.
  2. Open it and drag it to Applications (Mac), or run the installer (Windows).
  3. Click Install next to any app you want. Start with GridCraft or PdfCraft; they're the most useful day to day.

Prefer just one app? Use the download links in the table above.

Is it safe?

What I checked before installing

New software going viral is exactly when to be careful, so I checked before running anything:

✓ Real, established publisher. The ArtCraft GitHub org dates from 2021, has ~35k followers and real contributors, and a proper release pipeline.
✓ Apple-notarized. The Mac Launcher and GridCraft are signed by "Learning Machines LLC" and notarized, which means Apple scanned them for malware.
✓ Checksums match the published SHA-256 list.
✓ GridCraft can't phone home. I read the source code: it has no internet library at all.

I fully audited GridCraft and the Launcher, not every app. Ignore the star counts; they jumped by tens of thousands in days, so don't treat them as a safety signal. Get the apps only from the github.com/storytold links above, never from look-alike sites or ads.

The real unlock

Let your AI agent use them

Every app ships an MCP server. MCP is the plug that lets AI agents like Claude operate an app directly: open files, edit cells, lay out slides, export, with no screen-clicking. Each app exposes hundreds of commands (GridCraft: read and write ranges, formulas, charts, tables, sorting…).

  1. From an app's download page, grab the -cli- file (e.g. gridcraft-cli-…-macos-universal.zip), unzip it, and move gridcraft-cli somewhere on your PATH (e.g. /usr/local/bin).
  2. Connect it to Claude Code with one line:
claude mcp add gridcraft -- gridcraft-cli mcp
  1. Ask in plain English. For example:
"Build a 5-year DCF for a company with $100M revenue growing 12% in GridCraft, chart the free cash flow, and save it as dcf.xlsx." "Turn this earnings summary into a 6-slide deck in DeckCraft and export it as PDF."

The same pattern works for every app: swap gridcraft for deckcraft, pdfcraft, photocraft and so on.

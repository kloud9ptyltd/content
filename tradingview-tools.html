01 · pAulseperformance / awesome-pinescript

Awesome Pine Script

FREE2.0K STARSMITNO CODE NEEDED

One curated list of everything Pine Script: indicators, strategies, screeners, libraries and learning guides, each linking to the script on TradingView. It saves you digging through thousands of public scripts to find the good ones.

Use case: you want a volume profile, a flag finder or a killzone indicator, and you would rather add a tested free one than pay for it or write it.

How to use it
  1. Open the list and jump to Indicators or Strategies.
  2. Click a script. It opens on TradingView.
  3. Press Add to favorites, then find it under Indicators on your chart.
  4. Want to learn to write your own? Use the Learning Resources section at the bottom.

02 · tradingview / lightweight-charts

Lightweight Charts

FREE17.9K STARSAPACHE-2.0JAVASCRIPT

TradingView's own open-source chart engine. It draws fast, interactive candlestick, line and area charts on any web page, using your own data.

Use case: you built a bot or a backtest and want to see its trades on a TradingView-style chart, or you want a clean chart on your own dashboard or site.

How to start
  1. Install it: npm install lightweight-charts
  2. Create a chart and give it your candles:
import { createChart, CandlestickSeries } from 'lightweight-charts';

const chart = createChart(document.body, { width: 800, height: 400 });
const candles = chart.addSeries(CandlestickSeries);
candles.setData([
  { time: '2026-11-13', open: 100, high: 104, low: 99, close: 103 },
  { time: '2026-11-14', open: 103, high: 106, low: 101, close: 102 },
]);

Not a coder? Paste the link into Claude or ChatGPT and ask it to chart a CSV of your trades with this library.

03 · shner-elmo / TradingView-Screener

TradingView Screener

FREE1.4K STARSMITPYTHON

A Python package that builds custom screeners on TradingView's data: stocks, crypto, forex, futures and options, with more than 3,000 fields and timeframes from one minute to one month.

Use case: every morning you want the stocks with unusual volume and a fresh MACD cross, as a table you can save or feed into a bot, without clicking through the screener by hand.

How to start
  1. Install it: pip install tradingview-screener
  2. Write your filters and run it:
from tradingview_screener import Query, col

count, df = (Query()
  .select('name', 'close', 'volume', 'relative_volume_10d_calc')
  .where(
      col('relative_volume_10d_calc') > 1.2,
      col('MACD.macd') >= col('MACD.signal'),
  )
  .order_by('volume', ascending=False)
  .limit(25)
  .get_scanner_data())
print(df)

It returns 50 rows by default. Keep your requests modest; the author warns that heavy use can get you blocked.

04 · fabston / TradingView-Webhook-Bot

Webhook Bot

FREE1.9K STARSMITPYTHON

A small server that listens for your TradingView alerts and forwards them to Telegram, Discord, Slack or email, with the ticker and price filled in.

Use case: your strategy fires an alert and you want it in a Telegram or Discord channel straight away, for yourself or for a group you trade with.

How to start
  1. Clone it and install: git clone https://github.com/fabston/TradingView-Webhook-Bot.git, then pip install -r requirements.txt
  2. Put your Telegram or Discord details and a secret key in config.py.
  3. Run python main.py on a machine that stays online.
  4. In a TradingView alert, tick Webhook URL, point it at your server's /webhook address, and use a message like this:
{
  "key": "your-secret-key",
  "msg": "Long {{ticker}} at {{close}}"
}

Two honest catches: TradingView only sends webhooks on its paid plans, and the bot needs a server that is always on.

05 · tradesdontlie / tradingview-mcp

TradingView MCP

FREE7.2K STARSJAVASCRIPTWORKS WITH CLAUDE CODE

Connects Claude to the TradingView desktop app running on your computer, so the AI can read your live chart: the symbol, your indicator values, the levels you have drawn. It can also change symbols and timeframes, draw lines, and write and fix Pine Script for you.

Use case: ask "what is on my chart?" and get a read of trend, levels and indicators in plain English, or describe an indicator and have Claude write it and load it onto the chart.

How to start
  1. You need the TradingView desktop app, Node.js 18 or newer, and Claude Code.
  2. Paste this into Claude Code and let it do the setup:
Install the TradingView MCP server. Clone https://github.com/tradesdontlie/tradingview-mcp.git, run npm install, add it to my MCP config, and launch TradingView with the debug port. Then verify the connection with tv_health_check.
  1. Then ask: "What's on my chart?" or "Give me a full analysis."

Good to know: it is an unofficial tool, it does not place trades, everything runs on your own machine, and the author says you need a TradingView subscription for real-time data.

02 · Good to know

Honest notes.

The tools are free. TradingView itself may not be. Webhook alerts need a paid TradingView plan, and the MCP author says real-time data needs a subscription. Numbers one to three work with a free account.
Only Lightweight Charts is made by TradingView. The other four are community projects and are not endorsed by TradingView. Unofficial tools can break when TradingView changes something.
Read the code before you run it, or ask an AI assistant to explain what it does. That goes for anything you download from GitHub.
An indicator is a tool, not a signal. Test anything from the Pine Script list on past data before you trust it with money.
AI can misread a chart. Treat its read as a second opinion and check the levels yourself.

01 · What you get

Your own stock market terminal, for $0.

OpenStock is made by Open Dev Society and released under the AGPL-3.0 licence, so the code is public and free to run yourself. Under the hood it combines TradingView's free chart widgets with market data from Finnhub, wrapped in a clean app with an account and a watchlist.

My own install: the market overview with the index pulse, leaders and the S&P 500 heatmap.

  1. 7 markets

    US, India, Germany, Canada, Australia, crypto and forex, with a sector heatmap, leaders and top stories.

  2. ⌘K search + tabs

    Search every exchange Finnhub covers and keep stocks open as browser-style tabs.

  3. Stock pages

    Live candles with drawing tools (trend lines, Fibonacci, shapes, text), financials, technicals and the company profile.

  4. Watchlist

    Up to 50 stocks, saved to your account.

  5. Price alerts + AI news digest

    Built in, but they need email set up (and "realtime mode" for alerts). Optional.

  6. What it isn't

    It's a free terminal for charts and research, not Bloomberg-grade data. Quotes refresh hourly by default (charts are live), and some markets are delayed: India and Germany chart end of day.

04 · Run your own

Your own copy in 5 steps.

Running your own copy means your own data limits, and you can switch on 15-second quotes. You need a computer (Mac, Windows or Linux) and about 10 minutes. Everything below is free.

  • 1

    Install Node.js 22 and Git. Download Node.js 22 LTS from nodejs.org and Git from git-scm.com.

  • 2

    Get a free Finnhub key. Sign up at finnhub.io and copy your API key from the dashboard. The free key allows 60 requests a minute.

  • 3

    Get a free database. Create a free cluster on MongoDB Atlas and copy its connection string (it starts with mongodb+srv://). If you use Docker, the repo's docker-compose.yml runs one for you instead.

  • 4

    Download and configure. Run the commands below, then open the new .env file and fill in three lines: MONGODB_URI, BETTER_AUTH_SECRET (any long random text) and FINNHUB_API_KEY.

  • 5

    Start it and sign up. Open http://localhost:3000/sign-up, create an account (it stays on your own database), open any stock, click Indicators and tick all 8.

Terminal · Mac / Linux
git clone https://github.com/Open-Dev-Society/OpenStock.git
cd OpenStock
npm ci
cp .env.example .env          # then fill in the 3 lines
node scripts/check-env.mjs    # checks your .env
npm run dev                   # open http://localhost:3000

On Windows, use copy .env.example .env instead of cp. For 15-second quotes, add NEXT_PUBLIC_OPENSTOCK_DATA_MODE=realtime to .env and restart. Keep your .env private: it holds your keys.
